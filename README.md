## ⚙️ Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/deevesh-portfolio.git
```

**2. Navigate to the project folder**

```bash
cd deevesh-portfolio
```

**3. Launch the website**

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.

No package installation is required for a standard HTML, CSS, and JavaScript project.
